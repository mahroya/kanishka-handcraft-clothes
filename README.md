Kanishka Legacy – Handcrafted Clothing Website

Kanishka Legacy is a website showcasing handmade clothing designs and unique handcrafted fashion pieces.

I created this project to combine my interest in technology and creativity while exploring how web development can help traditional crafts and small businesses reach a wider audience.

Features
Elegant homepage introducing the brand.
Product images and descriptions.
User-friendly website navigation.
